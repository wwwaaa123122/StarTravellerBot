Web 管理后台 ​

StarTraveller 提供一个独立于机器人主进程的 Web 管理后台（webadmin/），用于在浏览器中查看系统状态、管理用户与插件。它基于 Flask 构建，按需读取机器人的数据文件，不修改 client.py / main.py 的运行逻辑。

功能总览 ​

前端为纯静态实现（webadmin/static/，原生 HTML/CSS/JS，无构建依赖），登录后进入管理面板：

页面功能
总览统计卡片（用户/消息/AI 调用/Token/插件/积分/RAG/访问）、近 14 天签到趋势、AI 调用统计（请求数/Token/延迟/错误率/费用）、角色分布
插件插件列表（名称/关键字/帮助/状态），开关切换即写入 reload.flag，机器人 ~10s 内热重载生效
权限ROOT_User（管理员）、black_list（黑名单，消息被静默忽略）、allow_ai 开关
AI 设置提供商（DeepSeek/OpenAI 兼容 / Gemini）、模型、Base URL、Max Tokens、Temperature、API Key（掩码显示，留空不修改）
用户全部签到用户（昵称 / OpenID / 积分 / 好感度 / 连续天数 / 最近签到 / 角色）
记忆检索所有用户的 RAG 对话记忆记录
定时定时群发配置（启用状态 / 发送时间 / 通知群数 / 最近发送日期 / 内容）
配置机器人配置（敏感字段脱敏展示）与运行信息

机器人状态（在线/离线）每 15s 自动刷新；登录采用 Bearer token（HMAC 签名，7 天有效），登录接口有 IP 级频率限制。

启动方式 ​

随机器人自动启动 ​

在 .env 中配置 webadmin 相关环境变量后，main.py 会以守护线程方式随机器人同步启动管理后台，不影响机器人事件循环：

env
STAR_TRAVELLER_ADMIN_ENABLED=true
STAR_TRAVELLER_ADMIN_HOST=0.0.0.0
STAR_TRAVELLER_ADMIN_PORT=8765
STAR_TRAVELLER_ADMIN_PASSWORD=你的强密码

独立启动 ​

bash
python -m webadmin.server --host 0.0.0.0 --port 8765

配置优先级 ​

  1. 启动参数（--host / --port / --password）
  2. 环境变量 STAR_TRAVELLER_ADMIN_HOST / _PORT / _PASSWORD
  3. .env 的 webadmin 段（STAR_TRAVELLER_ADMIN_*）
  4. 内置默认值（0.0.0.0:8765，密码 admin123）

安全提示：默认监听 0.0.0.0（所有网卡），访问时不校验 Host 头端口，请务必设置强密码，避免使用默认密码 admin123。

访问与登录 ​

启动后访问 http://服务器IP:8765/admin，输入密码即可登录。Token 有效期 7 天，登录接口带速率限制（1 分钟内的失败尝试）。

界面预览 ​

仪表盘 ​

仪表盘集中展示机器人运行的核心指标：用户总数、今日签到人数、累计积分、角色数量、RAG 记忆条数、插件数量与访问统计，并绘制近 14 天签到趋势与角色分布图。

用户管理 ​

用户管理页列出所有签到用户，展示昵称、积分、连续签到天数、好感度与当前角色，支持关键字搜索。

支持对用户进行核验操作，便于管理群成员状态。

系统设置 ​

系统设置页展示机器人配置与运行信息，密钥类字段（密码、Secret、Token、AppID 等）自动脱敏显示，避免敏感信息泄露。

响应式布局 ​

管理后台适配桌面端与移动端：

API 端点 ​

方法路径说明
POST/admin/api/login登录，body {"password": "..."}，返回 Token
GET/admin/api/ping存活检测
GET/admin/api/overview仪表盘数据
GET/admin/api/status系统状态（CPU / 内存 / 磁盘 / 开机时长）
GET/admin/api/users用户列表
GET/admin/api/memoryRAG 记忆记录
GET/admin/api/plugins插件列表
GET/admin/api/schedule定时任务配置
GET/admin/api/config机器人配置（脱敏）

除 login 与 ping 外的接口均需携带请求头 Authorization: Bearer <token>。
